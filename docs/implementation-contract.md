# Internal component contract

Package: `weather_pipeline`. Python 3.12, PySpark 4.0.1, DuckDB 1.4.0.

Raw ingestion is newline-delimited JSON, one envelope per observation:
`batch_id`, `ingested_at` (UTC ISO string), `station_id`, `raw_json` (canonical JSON of the NWS GeoJSON observation feature).

Manifest JSON fields: `batch_id`, `ingested_at`, `start`, `end` (UTC ISO), `raw_path` (absolute), `stations` (list of dictionaries with `station_id`, `name`, `latitude`, `longitude`), `windows` (list of dictionaries with `station_id`, `start`, `end`), `advance_checkpoint` (boolean), `source` (`nws`), `manifest_path`, and optional source request metadata. File is committed only after all stations/pages succeed. `start` is the earliest window start. `end` is fixed before fetching. Each record preserves the original feature as `raw_json`.

Transform API: `create_spark()`; `transform_batch(spark, raw_path, output_dir, station_ids, reference_time) -> dict`. `reference_time` is manifest end (ISO). Output result keys: `curated_path`, `rejected_path`, `report`. Paths are absolute Parquet directories. Report counts: `input_count`, `accepted_count`, `rejected_count`, `duplicate_count`, `missing_measurement_count`. Input = accepted + rejected + duplicate. Curated columns: `station_id` string, `observed_at` timestamp UTC, `temperature_c` double nullable, `humidity_pct` double nullable, `wind_kph` double nullable, `text_description` string nullable, `latitude` double nullable, `longitude` double nullable, `payload_hash` string, `source_ingested_at` timestamp. Business key is station_id + observed_at. Reject required-field failures, invalid optional non-null values, unknown station, source station mismatch, invalid timestamps or timestamps later than reference_time plus 10 minutes. Deterministic duplicate winner by source_ingested_at descending then payload_hash descending. Missing optional measurements remain null. Rejected Parquet retains raw_json and reasons.

Warehouse API: `load_batch(db_path, manifest, result, fail_before_commit=False) -> dict`; `get_checkpoints(db_path) -> dict[str, str]`; `export_dashboard(db_path, output_dir) -> dict`; `warehouse_summary(db_path) -> dict`. Can initialize missing DB. Tables: dim_station, dim_date, fact_observation, etl_runs, source_checkpoints. One transaction for model load, successful audit and checkpoint. Merge key station_id + observed_at; changed payload only updates if incoming source_ingested_at >= existing; unchanged payload leaves fact unchanged. Checkpoints from window end, monotonic, only if advance_checkpoint. A committed batch ID is a no-op if replayed. Reject a batch-ID collision with different inputs. `fail_before_commit` enables rollback testing. Query views `dashboard_observations` (joined fact/dim with station_name and observation_date), `dashboard_daily`, `dashboard_quality`. CSV exports for BI, not a substitute for a native BI workbook.

Ingestion API: `NWSClient(user_agent, timeout=30, max_attempts=4)`; `ingest_batch(client, raw_root, windows, advance_checkpoint=True) -> dict`. windows as above. Raw root absolute Path. Network retries are bounded with backoff; requests never send secrets. Validate NWS pagination next links stay on api.weather.gov; incomplete pagination must fail. Metadata fetched from stations/{id}. Do not add a latest-only ingestion shortcut.

Root owns pyproject, CLI, orchestration, configuration, documentation and integration tests. Agents own ingestion.py + tests/test_ingestion.py, transform.py + tests/test_transform.py, warehouse.py + tests/test_warehouse.py, respectively.
